# lovelace-hass-foscam v0.1.0-alpha.4 — Touch controls and landscape fullscreen

- **Touch and hover:** PTZ hover mode is limited to devices with a fine pointer that supports hover. On touchscreens, use the PTZ button to show or hide the D-pad and presets.
- **Preview taps:** Empty space between PTZ buttons and preset chips no longer intercepts taps. Tap the preview to start the live stream or play the last recording, according to `image_click`.
- **Landscape fullscreen:** The camera view fits the visible fullscreen area, and the D-pad and lens buttons use a more compact layout on short landscape screens to avoid clipping.

Desktop testing passed. Verification in the Android Home Assistant app is still pending.
